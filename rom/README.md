# Boot ROM (not included)

The A590/A2091 boot ROM is Commodore copyright and is not distributed here.
Use your own 16 KB image (e.g. the 390721-07 / 390722-07 EPROM pair interleaved,
U13 = even bytes, or a Cloanto `amiga-boot-a590.rom` with its `rom.key`) and
copy it to the Amiga games folder on the MiSTer as `a2091.rom`.

Tested with the -07 pair: MD5 of the 16 KB image `605e924ed2c6b015e2fbb80d508a2fa4`.
